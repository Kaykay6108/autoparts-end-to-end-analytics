# Upload Instructions

1. Extract this ZIP file.
2. Open the extracted `autoparts_repo_upload_pack` folder.
3. In your GitHub repository, choose **Add file → Upload files**.
4. Drag all folders and `.gitignore` into the upload area.
5. Do not upload this ZIP file itself.
6. Commit message: `Add project files and repository structure`.

The root README is not included because it was already added separately.
